# 2026-2학기 교사 시간표 웹앱

Google Sheet의 `원본(818)`과 `수강현황(818)` 탭을 읽어 교사별 시간표를 표시하는 정적 웹앱입니다.

## 데이터 기준

- `원본(818)`: 전체 교사별 시간표
- `수강현황(818)`: `교사명 + 학년 + 블록`으로 과목명과 학생 수를 찾는 매핑
- `시간표 조회`: 원본 시트에서 계산되는 조회용 탭이지만, 웹앱은 직접 `원본(818)`과 `수강현황(818)`을 읽습니다.

## 표시 규칙

- `A`부터 `H`까지만 포함된 값은 과목명을 붙이지 않고 그대로 표시합니다.
- `ABCD`, `EFGH`처럼 여러 기본 블록이 동시에 들어간 값도 그대로 나열합니다.
- `2/M`, `2G1`, `3/N`처럼 학년과 블록이 있는 값은 `2M(과목명)` 형식으로 표시합니다.
- `D3`처럼 교사 기준으로 한 과목에만 연결되는 블록은 `D3(과목명)` 형식으로 표시합니다.
- 수강현황과 매칭되는 시간에는 `수강인원 n명` 버튼이 표시되고, 클릭하면 수강생 명단 팝업이 열립니다.
- 교사 이름을 직접 입력해 조회할 수 있고, 교사 선택 목록은 검색어에 맞게 좁혀집니다.
- `1h`, `A~H`, `2M`, `3M`, `3V` 시트가 있으면 해당 시트의 모듈별 명단을 수강생 팝업에 우선 반영합니다.
- `2m135v2`, `2m24v13`, `3m12345`, `3m67v123`처럼 압축된 모듈 표기는 각 모듈 명단으로 풀어 표시합니다.

## 휴대폰 설치

이 앱은 PWA로 설정되어 있어 기존 웹 주소를 그대로 사용하면서 휴대폰 홈 화면에 설치할 수 있습니다.

- iPhone: Safari에서 배포 주소를 연 뒤 공유 버튼을 누르고 `홈 화면에 추가`를 선택합니다.
- Android: Chrome에서 배포 주소를 연 뒤 메뉴에서 `앱 설치` 또는 `홈 화면에 추가`를 선택합니다.
